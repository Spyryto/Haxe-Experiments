# Haxe Experiments

Un laboratorio di piccoli esperimenti Haxe, provabili via browser o come applicazioni native compilate da GitHub Actions.

Ogni esperimento ha codice sorgente, istruzioni e un obiettivo misurabile. Le build vengono validate dalla CI: nessun risultato e dichiarato pronto se non supera il workflow.

> Work in progress: i primi esperimenti saranno aggiunti su branch dedicati con pull request.
